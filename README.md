## Installation

### Requirements

- **[KDE Plasma](https://kde.org/)** desktop environment
- **[Konsave](https://github.com/Prayag2/konsave/)** (dotfiles backup tool)
- **Bash** (usually pre-installed on Linux)

### Install configs

```bash
chmod +x install.sh
./install.sh
```
